The fast way · Step 2 of 5

Paste one line

Copy the line below, paste it into the Terminal, press Return. Then leave it alone.

curl -fsSL https://raw.githubusercontent.com/daemnapps/outlier/main/install.sh | bash

What happens

It checks what you already have, installs what's missing, downloads the toolkit, and asks you for one key. Takes about five minutes.

It prints a ✓ for each thing it finishes.

Good to know

It's safe to run twice. If it stops partway, run the same line again — it picks up where it left off and skips whatever's already done.

If something breaks

Open a question and paste the red text into it — all of it, even the parts that look irrelevant. Ask here. It gets answered under your question and stays there.

Never paste an API key. If the error text has one in it, replace it with XXXX first.

Two rules

Read what it writes before it goes anywhere. It won't publish, send or spend on its own.

Tell it when it's wrong. It keeps the correction, and the second run is much better than the first.
The long way · Step 1 of 14

Open the Terminal

Hold Command and press Space.
Type terminal.
Press Return.

Click Start.
Type powershell.
Click Windows PowerShell.

What happens

A window opens with some text in it. Leave it open — you'll use it the whole way through.

Good to know

This is just a box where you type instead of click. You'll type about eight lines in total. You can't break your computer with anything in this guide.
The long way · Step 2 of 14

Check you have Git

Copy the line below. Paste it into the Terminal. Press Return.

git --version

What happens

You should see something like git version 2.39.5.

If that didn't work

If it says command not found:

Mac — paste xcode-select --install, click through the installer, then try again.

Windows — get it from git-scm.com/downloads, run the installer, click Next on everything. Then close the Terminal, open a new one, and try again.
The long way · Step 3 of 14

Check you have Python

Same thing. Copy, paste, Return.

python3 --version

What happens

You want a number that starts with 3.9 or higher.

If that didn't work

If it says command not found, get it from python.org/downloads.

On Windows, tick the box that says Add Python to PATH during install. It's easy to miss and it matters.
The long way · Step 4 of 14

Install Claude Code

This is the program that runs everything else.

curl -fsSL https://claude.ai/install.sh | bash

What happens

Wait for it to finish. Then close the Terminal window and open a new one.

That part matters — the new window is the one that knows the program exists.

Good to know

On Windows, if that line doesn't work, download it from claude.ai/download and run the installer instead.
The long way · Step 5 of 14

Check it installed

In your new Terminal window:

claude --version

What happens

A version number means you're past the hardest part.

If that didn't work

Nothing? You probably didn't open a new window. Close it, open a fresh one, try again.
The long way · Step 6 of 14

Make your folder

One folder holds everything. Paste this:

mkdir -p ~/outlier

What happens

Nothing visible happens. That's normal — it made a folder called outlier.

Good to know

On a Mac you can see it: open Finder, hold Command and Shift, press H. It's a normal folder. You can open it and look inside whenever you want.
The long way · Step 7 of 14

Go into the folder

Now move into it:

cd ~/outlier

What happens

Again, nothing visible. To check it worked, paste pwd — it should print something ending in /outlier.

Good to know

cd means change directory. You'll use this line every time you come back.
The long way · Step 8 of 14

Copy the toolkit in

This downloads everything into your folder.

git clone https://github.com/daemnapps/outlier.git .

What happens

The dot at the end matters. It means put it right here.

When it finishes, paste ls — you should see a list of folder names.

Good to know

This might take a minute. Let it run.
The long way · Step 9 of 14

Install a browser it can use

The toolkit needs its own browser to look at competitor pages.

python3 -m pip install --user playwright

What happens

Lots of text will scroll past. That's fine. Wait for it to stop.
The long way · Step 10 of 14

Install a video tool

Paste this:

brew install ffmpeg

If it says brew: command not found, first paste this and let it finish, then try again:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Go to ffmpeg.org/download.html and follow their Windows steps.

What happens

This one's only needed for video work. If it gives you trouble, skip it and come back later — everything else still works.

Good to know

Optional for now. Don't get stuck here.
