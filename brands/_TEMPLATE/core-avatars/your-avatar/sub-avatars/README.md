# Sub-avatars

A sub-avatar is the same person, narrowed — same core desire, different
situation or vocabulary. One file each.

Keep only the DELTA here: what is different from the core avatar's profile,
plus the 10–30 phrases this narrower person uses that the core one does not.
Everything else inherits from the parent.

If a sub-avatar's delta grows past a few dozen phrases, it is a core avatar
trying to get out — promote it.
