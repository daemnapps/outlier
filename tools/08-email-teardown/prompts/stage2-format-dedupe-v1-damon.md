Turn them into a **format set**: the small number of layouts this brand
actually reuses, each one named, so every future email is built as a known
format rather than designed from nothing.

**Group by layout skeleton, never by topic.** A Black Friday email and a
welcome email with the same block order are the same format. A product
spotlight and a proof drop with different block orders are two formats. The
campaign the design served is not a property of the format. If you find
yourself naming a format after a season, an offer or a product, you have
grouped by topic and the set is wrong.

**The set is as big as the evidence says.** Do not aim for a number. Do not
force outliers into a family to keep it tidy, and do not split a family
because two members have different colors. A brand with a year of sends
usually lands somewhere between six and a dozen formats — but that is an
observation about other brands, not a target for this one.

**Nothing is invented.** Every format must be backed by emails that exist in
the record, cited by their ids. A format with one member is a **candidate**,
not a format, and gets labelled as such. A format you think the brand *should*
have does not go in the set at all.

**Frequency is a finding.** How often a format is used, and whether its use is
rising or falling across the record, tells us what is working and what has
been quietly abandoned. Report it; never smooth it.

Give me these five sections.

**1. THE FORMAT SET**

One block per format, numbered `FMT-01`, `FMT-02`, … Order by how often the
format is used, most-used first. For each:

- **CODE AND NAME** — `FMT-03 · BIG TYPE + STEPS`. The name says what the
  layout is, not what it sells. Three words or fewer.
- **SIGNATURE** — the one-line skeleton, in stage 1's signature form.
- **WHAT IT IS FOR** — the job this layout does, in one sentence. What kind
  of argument it carries well.
- **BLOCK ORDER** — the canonical top-to-bottom block sequence, as an arrow
  chain. This is the format's identity; everything else is dressing.
- **WHAT VARIES BETWEEN MEMBERS** — the parts members disagree on (ground
  color, image count, CTA repeats, length). These become the format's options.
- **WHAT NEVER VARIES** — the parts every member shares. These become the
  format's rules.
- **MEMBERS** — every email id in this format, with its board. Then the count,
  and the date range it spans.
- **THE BEST MEMBER** — the one email that most completely expresses the
  format, and one line on why it is the reference.

**2. THE CANDIDATES**

Formats with only one or two members. Same fields, shorter. Say plainly for
each whether it looks like an experiment worth repeating or a one-off that
served a single send.

**3. THE ORPHANS**

Every email that fits no format and is not a candidate. List them by id with
one line each on why they stand alone. Do not force them anywhere. A long
orphan list is a finding about the brand's design discipline, and I want to
see it.

**4. THE SHARED MODULES**

The pieces that appear across formats rather than inside one — header, brand
mark, nav, footer, CTA band, preheader, legal, whatever is actually shared.
Number them `MOD-01`, `MOD-02`, … For each: what it is, its exact geometry,
which formats use it, and whether it varies at all between them. These get
built once and reused; the format specs will reference them by code.

**5. WHAT THE SET SAYS**

Four short paragraphs, no hedging:

- **The spine** — which two or three formats carry most of the sending, and
  what that says about how this brand argues.
- **The drift** — what changed across the record. Formats that appeared,
  formats that stopped, a design language that shifted. Cite the dates.
- **The gaps** — jobs the brand clearly needs to do that no format in the set
  is built for. Only jobs the record itself evidences.
- **The risk** — where the set is thin: formats resting on few members,
  groupings you are least confident in, anything a second reader should check.
