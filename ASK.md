# Asking a question

There is no group chat, no support email, and no DMs. Questions go in one
place: **the Questions tab on this repo.**

**[→ Ask a question](https://github.com/daemnapps/outlier/issues/new?template=question.yml)**

That link opens a short form. Fill it in, press the green button, done. You
need a free GitHub account — the same one you'd make to download this anyway.

## Why here and not a chat

Three reasons, and they're all in your favour:

1. **It gets answered.** A question in a group chat scrolls away in an hour.
   A question here sits there until it has an answer under it.
2. **It gets answered once.** The next person who hits the same wall finds
   your question already answered instead of asking it again.
3. **It gets a real answer.** I run the answers against the actual toolkit —
   the prompts, the code, the runs I've done — not off the top of my head in
   a chat window.

## What makes a question easy to answer

- **Paste the red text.** All of it. The part you think is irrelevant is
  usually the part that says what happened.
- **Say what you expected.** "It should have listed the ads" tells me more
  than "it didn't work."
- **Say where you were.** Which walkthrough step, or which command you ran.

## What not to paste

Never paste an API key, a password, or the contents of a `.env` file. If your
error text has one in it, replace it with `XXXX` first. Anything posted here
is public.

## Before you ask

Check the two places the answer usually already is:

- The [walkthrough](WALKTHROUGH.md) — most setup problems are a step that got
  skipped.
- The [answered questions](https://github.com/daemnapps/outlier/issues?q=is%3Aissue+label%3Aquestion)
  — search yours before you post it.

## How fast

No promise. This is a free thing I maintain between real work. Most get
answered within a few days; some get answered in an hour. If yours is still
sitting there after a week, add a comment saying so and it moves up.
